# 期权扭蛋 · Options Gacha

把期权知识做成抽卡游戏：每天 10 包、每包 3 张，收集图鉴、重复卡升级、战斗力对战。

- **卡池**：精选自小隐寺投资百科《期权进阶》（共 344 篇词条），v1 共 113 张；卡面为一句话摘要，点开可跳转读原文。
- **稀有度**：N 基础概念 · R 一阶希腊字母与常用策略 · SR 策略组合 · SSR 二阶希腊与定价模型 · UR 奇异期权。
- **玩法**：扭蛋抽卡 / 图鉴收集 / 重复卡合成升级（2/4/8/16…）/ 对战 / 奖杯成就。进度保存在浏览器 localStorage，无需注册。

## 使用

打开 `index.html` 即可游玩（或通过 GitHub Pages 在线访问）。
